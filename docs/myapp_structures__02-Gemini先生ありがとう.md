# フレキシブル入退室管理アプリ（修正・改善版）

---

## 主な仕様

- 開発・コーディング環境: Github-Codespaces
- フロントエンド言語: HTML, CSS, JavaScript（Vue.jsを積極的に利用）
- サーバーサイド言語: Java（フレームワーク「SpringBoot」を積極的に利用）
- データベース: MySQLを「Aiven」で利用。難しいようならSpringBoot内蔵のH2Database
- セキュリティ・認証仕様:
  - パスワード管理: `BCrypt`アルゴリズムを用いてハッシュ化してデータベースに格納する。
  - アクセス制御: Spring Securityによる「Role-based Access Control (RBAC)」を導入。
  - ガード機能: 非ログインユーザーが直接URLを入力しても各画面へ遷移できないよう、インターセプター（Vue RouterのNavigation Guard等）を盛り込む。
  - 二重バリデーション: フロントエンド（Vue.js）でのチェックに加え、SpringBoot側でもリクエスト内容のバリデーションを厳格に実行する。

### 開発者向けコンセプト

- JavaやSpringBoot、フロントエンド側のVue.jsに関する初学者でも段階的に理解しやすいコーディング設計とコメント記述も特徴である。

## デプロイ先

- AWS、または期間限定ながら無料でデプロイしてオンライン利用できる環境を予定。

## 画面構成

### ログイン画面

- ユーザーID（メールアドレス） 入力欄
- パスワード 入力欄
- ログイン ボタン

### ユーザー登録画面

- ユーザー名 入力欄（入力必須）
- ユーザーID（メールアドレス） 入力欄（入力必須）
- パスワード 入力欄（入力必須）
- パスワード（確認用） 入力欄（入力必須）
- これで登録する ボタン / リセット ボタン

### 打刻画面（UX改善版）

- ボタン活性制御
  - 当日のEntryが未完了の場合、Exitボタンは非活性（グレーアウト）。
  - 当日のEntryが完了している場合、Entryボタンは非活性。
- Entry ボタン / Exit ボタン
- ハンバーガーメニュー（ヘッダー右上に配置）

### ダッシュボード画面

- 上段: お知らせメッセージ（予定申請や打刻申請の承認・差戻通知を含む。リンクから各申請画面へ遷移）
- 中段: 打刻画面へ ボタン / ログアウト ボタン
- 下段: 予定申請 / 打刻内容編集申請 / ユーザーアカウント情報編集 / （管理者用）各種管理ボタン

### 予定申請画面

- リストカレンダー: 操作日の7日前から30日分を表示。
- 申請フォーム: リストのボタン押下で表示。申請済みの場合は元の内容を反映。

### 打刻内容編集申請画面

- リストカレンダー: 操作日の当月1か月分を表示。
- 編集フォーム: Entry/Exit時刻（hh:mm:ss形式）の修正、備考入力。

### ユーザーアカウント情報編集画面

- 更新後は数秒のインターバル後に自動ログアウトする告知を表示。
- アカウント削除申請（2段階の確認ダイアログを経て実行）。

### （管理者用）各管理画面

- お知らせ情報登録、月別打刻状況参照出力、アカウント一覧参照編集。
- アカウント検索では、半角スペース区切りによる複数ワード検索に対応。

## バッチ構成

### 過去のユーザー打刻記録のCSV出力とDBテーブルからの削除

- 実行: 毎月1日 00:00
- 内容: 6カ月前のレコードを「BOM付きUTF-8」形式のCSVで出力し、その後物理削除。

### 月ごとのユーザー滞在時間集計記録のcsv出力

- 内容: 前月の各日における合計時間を算出し `○h○○m` 形式で出力。

### 削除可能なお知らせの一括削除

- `is_deletable` が1のレコードを月次で物理削除。

## データベースのテーブル構成

### 「apply_user_accounts」テーブル

- `account_id`: varchar(36)。UUIDを利用した一意識別ID。
- `user_name`: varchar(30)
- `user_id`: text (メールアドレス形式)
- `password`: text (BCryptでハッシュ化された値)
- `is_auth`: int(1) (0:一般, 1:管理者)
- `quit_demand`: int(1)
- `about`: text
- `created_at / last_login_at`: datetime

### 「entry_exit_calendar」テーブル

- `record_id`: varchar(20)。登録日の `yyyyMMddhhmmssss` + UUID末尾4桁。
- `record_date`: date (日付型として定義)
- `registed_account_id`: varchar(36)
- `entry / exit`: datetime (内部はDATETIME型で保持。表示時に文字変換)
- `is_schedule_demand / is_timechange_demand`: int(1)
- `schedule_status / timechange_status`: int(1) (0:未承認, 1:差戻, 2:承認済)
- 各種申請・承認メッセージ用カラム（text型）

### 「announcement」テーブル

- `announcement_id`: varchar(36)。UUIDを利用。
- `announcement_title`: varchar(50)
- `announcement_about`: text
- `is_deletable`: int(1)

## 画面機能共通仕様

- 登録・申請時は必ず確認アラートを表示。
- CSV出力時は、日本語環境での閲覧を考慮したエンコーディング（BOM付きUTF-8等）を採用。
